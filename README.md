# zrigou.com

Portfolio of Mohamed Zrigou, a full-stack web and mobile developer based in Agadir, Morocco.
Built with Next.js (App Router), React 19 and Tailwind CSS 4.

## Run it

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm start            # serve the production build
npm run check-lint
```

## Where things live

| Path | What |
| --- | --- |
| `src/data/site.js` | Name, contact details, navigation, experience, services, skills |
| `src/data/projects.js` | Every project and case study. Adding an entry creates its page, sitemap URL and social image |
| `src/lib/schema.js` | JSON-LD structured data (Person, WebSite, ProfilePage, SoftwareApplication, BreadcrumbList) |
| `src/lib/og.jsx` | Social share images, generated per page |
| `src/components/ZelligeCanvas.jsx` | The interactive hero background |
| `public/images/projects/` | Project screenshots, WebP |
| `public/downloads/` | Files offered for download, such as the Masroufi APK |

## Project images

Screenshots are real captures, saved as WebP at roughly 1680px wide for browser views and 640px for phone and
panel views. Keep new ones in the same range to stay light.

## Masroufi APK

`public/downloads/masroufi.apk` is served from the site and linked from `/projects/masroufi`. The file is about
98 MiB, close to GitHub's 100 MiB limit. To host it elsewhere, such as a GitHub Release, set
`download.url` for Masroufi in `src/data/projects.js` and delete the file.

## SEO

Titles, descriptions, canonical URLs, Open Graph and Twitter cards are set per page. `sitemap.xml`, `robots.txt`
and the web manifest are generated by Next.js. Security headers and a Content-Security-Policy are set in
`next.config.mjs`.
